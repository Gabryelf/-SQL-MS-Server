#### Тема уроков 3 - 4. Типы данных и создание таблиц
 
*Расшифровка:*
- **Теория баз данных** Виды и типы баз данных. Создание и работа с таблицами. 
- **Практика** Работа внутри SSMS оболочки. Знакомство с основными типами и параметрами. Создание баз данных и таблиц.

> [!IMPORTANT]
*Домашняя работа:*
>- **Установка ПО** Установите соответствующее ПО (SQL SERVER и SSMS среду) у себя на домашнем компьютере.
>                Если возникнут проблемы с установкой сообщите об этом на следующем уроке.
>- **Задание к уроку 3-4** Создайте два решения (проекта) в Microsoft SQL Server Managment Studio.
>  
>Первый проект назовите "Типы данных" или похожим названием и в нем сохраните запрос
> 
>  
>>  - один или несколько  для работы с переменными и типами данных (целочисленные, символьные, с плавающей точкой)
>> 
>Второй проект назовите "Таблицы" или похожим названием и в нем сохраните запрос
>> - один для работы с созданием таблицы (не забудьте название, аргументы и типы)
>> - второй для работы с наполнением таблицы (заполняйте так что бы данные успешно внеслись в таблицу)
>
> Инициализируйте git в папке с решением (если еще не сделали этого) и сохраните в репозиторий GitHub
