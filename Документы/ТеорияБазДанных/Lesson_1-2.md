#### Тема уроков 1 - 2. Введение в теорию баз данных
 
*Расшифровка:*
- **Теория баз данных** Виды и типы баз данных. История развития СУБД. Реляционная модель (Кодд). 
- **Практика** Установка SQL SERVER и SSMS оболочки. Создание баз данных и таблиц.

> [!IMPORTANT]
*Домашняя работа:*
>- **Установка ПО** Установите соответствующее ПО (SQL SERVER и SSMS среду) у себя на домашнем компьютере.
>                Если возникнут проблемы с установкой сообщите об этом на следующем уроке.
>- **Задание к уроку 1-2** Создайте решение (проект) в Microsoft SQL Server Managment Studio.
>                Проект назовите "Базы_данных" или похожим названием и в нем сохраните два запроса
>                - один на создание базы данных (любое название)
>                - второй на удаление базы данных которая была создана.
>                Инициализируйте git в папке с решением и сохраните в репозиторий GitHub 
>                Ссылку прикрепите к текущему домашнему заданию.
