>
>**Модуль 2** Работа с данными в MS SQL.

#### Тема уроков 5 - 6. Схемы и функции.
 
*Расшифровка:*
- **Теория баз данных** Знакомство со схемами. Основные функции TSQL.
- **Практика** Работа внутри SSMS оболочки. Создаем схемы и таблицы в них. Транспортировка таблиц между схемами.

> [!IMPORTANT]
*Домашняя работа:*
>- **Установка ПО** Установите соответствующее ПО (SQL SERVER и SSMS среду) у себя на домашнем компьютере.
>                Если возникнут проблемы с установкой сообщите об этом на следующем уроке.
>- **Задание к уроку 5-6** Создайте решение (проект) в Microsoft SQL Server Managment Studio.
>  
>Проект назовите "Схемы" или похожим названием и в нем сохраните два запроса запроса
> 
>> - один для работы с созданием схем (создайте в нем 2 схемы сразу)
>> - второй для работы с транспортировкой таблицы из одной схемы в другую (для создания таблицы в схеме используйте заготовку и не забудьте добавить префикс имени схемы)
>
> Инициализируйте git в папке с решением (если еще не сделали этого) и сохраните в репозиторий GitHub
