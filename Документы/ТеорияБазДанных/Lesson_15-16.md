#### Тема уроков 15 - 16. Создание кластерного индекса.
 
*Расшифровка:*
- **Теория баз данных** Знакомство с статистикой. Определение индекса.
- **Практика** Работа внутри SSMS оболочки. Создаем статистики. Практическое применение индекса и автоматическое заполнение таблиц.

> [!IMPORTANT]
*Домашняя работа:*
>- **Задание к уроку 15-16** В своем решении (проект) в Microsoft SQL Server Managment Studio напишити следующий функционал.
>  
>Проект который вы использовали ранее добавьте скриптами.
> 
>> - создайте решение `Кластерные индексы` дополнительным проектом к основному.
>> - используйте  `Create` таблицы (4-5 столбцов) при помощи автоматического заполнения и  `Insert` на `1 000 000` или больше строк.
>> - установите `SET STATISTIC IO ON` через скрипт и включите `план выполнения` через GUI интерфейс (кнопка вверху)
>> - просмотрите сводку (отчет) по единичному запросу `SELECT` и план выполнения для этого запроса, а так же сообщение от `STATISTIC IO` в консоле.
>> - запишите в комментариях результаты - примерный проход по дереву и прочитанные строки - числами
>> - создайте кластерный ключ через запрос `CREATE CLUSTERED INDEX ... ON ...` и повторите `SELECT` по поиску тех же данных.
>> - подсчитайте статистику и примерный проход по дереву теперь и запишите цифры результатов рядом с предыдущими - сравните!
